# 🎨 Template Prompt - Membuat Fitur Admin Baru

**Gunakan prompt ini ketika membuat fitur admin baru** (contoh: manajemen kategori, kursus, sertifikat, dll) untuk memastikan styling konsisten dengan fitur existing seperti produk dan pelatihan.

---

## 📋 Pre-Development Checklist

Sebelum mulai coding, siapkan:

- [ ] **Nama Fitur**: Ditentukan (contoh: "Manajemen Artikal")
- [ ] **Model Laraver**: Sudah ada atau akan dibuat
- [ ] **Routes**: api/web routes sudah direncanakan
- [ ] **Permissions**: Permission names sudah diputuskan
- [ ] **Database Fields**: Field struktur sudah dirancang
- [ ] **Primary Action Color**: Sudah dipilih (orange, indigo, teal, dll)

## 🎯 Golden Rules untuk Setiap Fitur Admin Baru

### Rule #1: Gunakan Template Struktur yang Proven
```
Setiap fitur admin HARUS punya 3 views:
├── resources/views/admin/[nama-fitur]/
│   ├── index.blade.php     (List view dengan search & pagination)
│   ├── create.blade.php    (Form untuk tambah data)
│   ├── edit.blade.php      (Form untuk edit data)
│   └── .prompt.md          (Documentation untuk konsistensi)
```

### Rule #2: Follow Proven Layout Pattern
```
Index View:
  1. Header Section (Title + Description + "Tambah [Item]" button)
  2. Session Alerts (success, error notifications)
  3. Main Card Container
     - Card Header (Icon + Title + Search bar)
     - Table Content (columns, rows, pagination)
     - Footer (Pagination controls)

Create/Edit Views:
  1. Header Section (Title + Icon + Description)
  2. Form Card Container
     - Section 1: Basic Info
     - Section 2: Details/Media
     - Section 3: Variants/Pricing (if applicable)
     - Footer: Save button + Cancel button
```

### Rule #3: Konsisten dengan Color Palette
```
Primary Color (untuk button utama, icons, highlights):
  - bg-[color]-600           (button background)
  - hover:bg-[color]-700     (button hover)
  - text-[color]-600         (icon color)
  - bg-[color]-50            (icon background)
  - shadow-[color]-200       (button shadow)
  - focus:ring-[color]-500   (input focus)

Status Colors (standart untuk semua features):
  - Emerald (#10b981)  = Success/Available/Active
  - Red (#ef4444)      = Danger/Deleted/Inactive
  - Amber (#f59e0b)    = Warning/Pending/Draft
  - Sky (#0ea5e9)      = Info/Detail/View

Neutral (standart untuk semua):
  - Gray-* = backgrounds, borders, text
  - White = card backgrounds
```

### Rule #4: Responsive Mobile-First Design
```
Breakpoints yang WAJIB:
  - Mobile (default)    : Single column, full width inputs
  - md (768px+)         : 2-3 columns, grid layouts
  - lg (1024px+)        : Enhanced spacing, wider containers

Contoh Grid:
  grid-cols-1 md:grid-cols-2 lg:grid-cols-3

Contoh Width:
  w-full md:w-72 (search bar)
  w-full md:w-96 (form inputs)
```

### Rule #5: Icon Standards
```
Gunakan HANYA Heroicons SVG (24px):
  - Plus      : Untuk "Tambah" button
  - Pencil    : Untuk "Edit" button
  - Eye       : Untuk "View" button
  - Trash     : Untuk "Delete" button
  - MagnifyingGlass : Untuk search
  - ChevronRight: Untuk navigasi/pagination

Inline SVG Pattern:
<svg class="w-6 h-6" fill="none" stroke="currentColor" viewBox="0 0 24 24">
  <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M12 4v16m8-8H4"></path>
</svg>
```

### Rule #6: Permission Checks Required
```
Setiap action HARUS punya permission check:

@can('[feature]-create')
  <a href="{{ route('admin.[feature].create') }}" class="...">
    Tambah [Item]
  </a>
@endcan

@can('[feature]-view')
  <a href="{{ route('admin.[feature].show', $item) }}" class="...">
    Lihat
  </a>
@endcan

@can('[feature]-edit')
  <a href="{{ route('admin.[feature].edit', $item) }}" class="...">
    Edit
  </a>
@endcan

@can('[feature]-delete')
  <form method="POST" action="{{ route('admin.[feature].destroy', $item) }}" class="inline">
    @csrf
    @method('DELETE')
    <button class="...">Hapus</button>
  </form>
@endcan
```

### Rule #7: Form Input Pattern (HARUS DIIKUTI PERSIS)
```blade
<div>
  <label class="block text-xs font-semibold text-gray-600 uppercase tracking-wider mb-2">
    Label Text <span class="text-red-500">*</span>
  </label>
  <input 
    type="text" 
    name="field_name" 
    value="{{ old('field_name', $item->field_name ?? '') }}"
    class="w-full px-4 py-2.5 bg-gray-50 border border-gray-200 rounded-xl text-sm focus:bg-white focus:ring-2 focus:ring-[PRIMARY-COLOR]-500 focus:border-transparent transition duration-200 outline-none @error('field_name') border-red-500 bg-red-50/50 @enderror"
    placeholder="Placeholder text">
  @error('field_name')
    <p class="text-red-500 text-xs mt-1.5">{{ $message }}</p>
  @enderror
</div>
```

### Rule #8: Button Pattern (HARUS DIIKUTI PERSIS)
```blade
<!-- Primary Button (untuk save/submit) -->
<button type="submit" class="bg-[PRIMARY-COLOR]-600 hover:bg-[PRIMARY-COLOR]-700 text-white font-bold py-2.5 px-6 rounded-xl shadow-lg shadow-[PRIMARY-COLOR]-200 transition duration-300">
  Save / Submit / Create
</button>

<!-- Secondary Button (untuk cancel) -->
<a href="{{ route('admin.[feature].index') }}" class="bg-gray-100 hover:bg-gray-200 text-gray-700 font-semibold px-6 py-2.5 rounded-xl transition">
  Cancel
</a>

<!-- Icon Action Buttons (View/Edit/Delete di table) -->
<a class="p-2 bg-sky-50 text-sky-600 hover:bg-sky-100 rounded-lg transition" title="View">
  <!-- Eye Icon -->
</a>
<a class="p-2 bg-amber-50 text-amber-600 hover:bg-amber-100 rounded-lg transition" title="Edit">
  <!-- Pencil Icon -->
</a>
<button class="p-2 bg-red-50 text-red-600 hover:bg-red-100 rounded-lg transition" title="Delete">
  <!-- Trash Icon -->
</button>
```

### Rule #9: Card Styling (STANDART UNTUK SEMUA)
```blade
<div class="bg-white rounded-2xl shadow-sm border border-gray-100 overflow-hidden">
  <!-- Card Header -->
  <div class="p-6 md:p-8 border-b border-gray-100 flex items-center justify-between">
    <div class="flex items-center gap-3">
      <div class="p-2 bg-[PRIMARY-COLOR]-50 rounded-xl text-[PRIMARY-COLOR]-600">
        <!-- Icon -->
      </div>
      <div>
        <h3 class="text-lg font-bold text-gray-800">Title</h3>
        <p class="text-xs text-gray-400">Subtitle/Description</p>
      </div>
    </div>
    <!-- Optional: Search/Action in header -->
  </div>
  
  <!-- Card Content -->
  <div class="p-6 md:p-8">
    <!-- Content here -->
  </div>
  
  <!-- Card Footer (jika ada pagination) -->
  <div class="p-6 md:p-8 border-t border-gray-100 flex items-center justify-between">
    {{ $items->links() }}
  </div>
</div>
```

### Rule #10: Status Badge Pattern
```blade
<!-- Success/Available Status -->
<span class="inline-block px-3 py-1 bg-emerald-100 text-emerald-700 text-xs font-semibold rounded-full">
  Tersedia
</span>

<!-- Danger/Inactive Status -->
<span class="inline-block px-3 py-1 bg-red-100 text-red-700 text-xs font-semibold rounded-full">
  Tidak Aktif
</span>

<!-- Warning/Pending Status -->
<span class="inline-block px-3 py-1 bg-amber-100 text-amber-700 text-xs font-semibold rounded-full">
  Menunggu
</span>

<!-- Info Status -->
<span class="inline-block px-3 py-1 bg-sky-100 text-sky-700 text-xs font-semibold rounded-full">
  Draft
</span>
```

## 📝 Step-by-Step Implementation Checklist

### Phase 1: Persiapan
- [ ] Tentukan primary color untuk fitur ini
- [ ] Buat model Laravel
- [ ] Buat migration
- [ ] Setup routes (create, store, edit, update, destroy)
- [ ] Setup permissions
- [ ] Buat controller dengan methods: index, create, store, edit, update, destroy

### Phase 2: Index View
- [ ] Buat file `resources/views/admin/[feature]/index.blade.php`
- [ ] Implementasikan layout: Header → Alert → Card
- [ ] Tambah search form dengan benar styling
- [ ] Buat table dengan kolom yang sesuai
- [ ] Tambah permission checks di action buttons
- [ ] Implementasikan pagination
- [ ] Test responsiveness (mobile, tablet, desktop)

### Phase 3: Create View
- [ ] Buat file `resources/views/admin/[feature]/create.blade.php`
- [ ] Gunakan form pattern yang exact dari guideline
- [ ] Buat sections sesuai data structure
- [ ] Implementasikan error handling
- [ ] Tambah save & cancel buttons
- [ ] Test responsiveness

### Phase 4: Edit View
- [ ] Buat file `resources/views/admin/[feature]/edit.blade.php`
- [ ] Copy structure dari create, adjust untuk edit
- [ ] Populate form dengan existing data
- [ ] Test form submission
- [ ] Test responsiveness

### Phase 5: Documentation
- [ ] Buat file `.prompt.md` di folder feature
- [ ] Document: color palette, special rules, anti-patterns

- [ ] Buat file `.agent.md` untuk AI guidance

### Phase 6: Testing & QA
- [ ] Test all CRUD operations
- [ ] Test permission checks
- [ ] Test search & pagination
- [ ] Test form validation
- [ ] Test mobile responsiveness
- [ ] Test error messages styling
- [ ] Check CSS classes consistency

## 🚫 Anti-Patterns (JANGAN LAKUKAN)

❌ Jangan membuat styling baru tanpa follow pattern
❌ Jangan mix dark mode classes (`dark:`)
❌ Jangan skip permission checks
❌ Jangan buat 3 views dengan styling berbeda
❌ Jangan ubah spacing/padding sesuai keinginan
❌ Jangan gunakan warna arbitrary (hanya gunakan defined colors)
❌ Jangan lupa responsive design (mobile dulu!)
❌ Jangan skip error message styling
❌ Jangan gunakan icon selain Heroicons
❌ Jangan buat form pattern yang berbeda dari guideline

## ✅ Contoh Implementasi: Manajemen Kategori

**Structure:**
```
resources/views/admin/kategori/
├── index.blade.php
├── create.blade.php
├── edit.blade.php
└── .prompt.md
```

**Color Scheme untuk Kategori:**
```
Primary Color: Indigo (#4f46e5)
  bg-indigo-600 / hover:bg-indigo-700
  bg-indigo-50 / text-indigo-600
  focus:ring-indigo-500
```

**Quick Start Index View:**
```blade
@extends('layouts.admin')

@section('content')

<div class="mb-8">

            <svg class="w-5 h-5" fill="none" stroke="currentColor" viewBox="0 0 24 24"><path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M12 4v16m8-8H4"></path></svg>
            Tambah Kategori
        </a>
        @endcan
    </div>
    @if ($message = Session::get('success'))
    <div class="bg-emerald-50 border border-emerald-200 text-emerald-700 px-4 py-3 rounded-xl flex gap-3">
        <span class="text-emerald-600">✓</span>
        <span>{{ $message }}</span>
    </div>
    @endif
</div>

<!-- Main Card -->
<div class="bg-white rounded-2xl shadow-sm border border-gray-100 overflow-hidden">
    <!-- Card Header -->
    <div class="p-6 md:p-8 border-b border-gray-100 flex items-center gap-3">
        <div class="p-2 bg-indigo-50 rounded-xl text-indigo-600">
            <!-- Icon -->
        </div>
        <div class="flex-1">
            <h3 class="text-lg font-bold text-gray-800">Daftar Kategori</h3>
            <p class="text-xs text-gray-400">Total: {{ $kategoris->total() }} kategori</p>
        </div>
        <!-- Search -->
        <form class="w-full md:w-72">
            <input type="text" name="search" value="{{ request('search') }}" placeholder="Cari kategori..." class="w-full px-4 py-2.5 bg-gray-50 border border-gray-200 rounded-xl text-sm focus:bg-white focus:ring-2 focus:ring-indigo-500 focus:border-transparent transition duration-200 outline-none">
        </form>
    </div>
    
    <!-- Table -->
    <div class="overflow-x-auto">
        <table class="w-full">
            <thead class="bg-gray-50 border-b border-gray-100">
                <tr>
                    <th class="px-6 py-3 text-left text-xs font-semibold text-gray-600 uppercase tracking-wider">No</th>
                    <th class="px-6 py-3 text-left text-xs font-semibold text-gray-600 uppercase tracking-wider">Nama Kategori</th>
                    <th class="px-6 py-3 text-left text-xs font-semibold text-gray-600 uppercase tracking-wider">Status</th>
                    <th class="px-6 py-3 text-center text-xs font-semibold text-gray-600 uppercase tracking-wider">Aksi</th>
                </tr>
            </thead>
            <tbody class="divide-y divide-gray-100">
                @forelse ($kategoris as $kategori)
                <tr class="hover:bg-gray-50 transition">
                    <td class="px-6 py-4 text-sm text-gray-900">{{ ($kategoris->currentPage()-1)*$kategoris->perPage() + $loop->iteration }}</td>
                    <td class="px-6 py-4 text-sm font-medium text-gray-900">{{ $kategori->nama }}</td>
                    <td class="px-6 py-4 text-sm">
                        @if ($kategori->is_active)
                        <span class="inline-block px-3 py-1 bg-emerald-100 text-emerald-700 text-xs font-semibold rounded-full">Aktif</span>
                        @else
                        <span class="inline-block px-3 py-1 bg-red-100 text-red-700 text-xs font-semibold rounded-full">Nonaktif</span>
                        @endif
                    </td>
                    <td class="px-6 py-4 text-sm flex gap-2 justify-center">
                        @can('kategori-view')
                        <a href="{{ route('admin.kategori.show', $kategori) }}" class="p-2 bg-sky-50 text-sky-600 hover:bg-sky-100 rounded-lg transition">
                            <!-- Eye Icon -->
                        </a>
                        @endcan
                        @can('kategori-edit')
                        <a href="{{ route('admin.kategori.edit', $kategori) }}" class="p-2 bg-amber-50 text-amber-600 hover:bg-amber-100 rounded-lg transition">
                            <!-- Pencil Icon -->
                        </a>
                        @endcan
                        @can('kategori-delete')
                        <form method="POST" action="{{ route('admin.kategori.destroy', $kategori) }}" class="inline" onsubmit="return confirm('Yakin?')">
                            @csrf @method('DELETE')
                            <button type="submit" class="p-2 bg-red-50 text-red-600 hover:bg-red-100 rounded-lg transition">
                                <!-- Trash Icon -->
                            </button>
                        </form>
                        @endcan
                    </td>
                </tr>
                @empty
                <tr>
                    <td colspan="4" class="px-6 py-8 text-center text-sm text-gray-500">Tidak ada kategori</td>
                </tr>
                @endforelse
            </tbody>
        </table>
    </div>
    
    <!-- Pagination -->
    <div class="p-6 md:p-8 border-t border-gray-100">
        {{ $kategoris->links() }}
    </div>
</div>
@endsection
```

## 💡 Tips & Tricks

- **Copy-paste dari existing feature**: Ambil produk atau pelatihan, rename classes dengan primary color baru
- **Test mobile dulu**: Buat mobile responsive dari awal, jangan di-akhir
- **Permission checks**: Jangan lupa! Ini penting untuk security
- **Search functionality**: Biasanya bukan form, tapi form dengan method GET dan name="search"
- **AlpineJS untuk interactivity**: Gunakan jika perlu dynamic behavior (file upload preview, conditional fields)
- **Tailwind utilities only**: Jangan tambah custom CSS, gunakan Tailwind utilities
