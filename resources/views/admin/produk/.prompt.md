# 🎨 Prompt - Konsistensi Styling Admin Produk

Ketika bekerja dengan views di folder `resources/views/admin/produk/`, ikuti prompt ini:

## 📌 Before Every Edit

**Sebelum membuat perubahan pada `index.blade.php`, `create.blade.php`, atau `edit.blade.php`:**

1. ✅ **Baca file `.instructions.md` di folder ini**
2. ✅ **Periksa styling yang sudah ada di file tersebut**
3. ✅ **Jika ada perubahan styling, terapkan ke SEMUA 3 file sekaligus**
4. ✅ **Gunakan warna blue (#f97316) sebagai primary color**
5. ✅ **Jangan ubah struktur layout tanpa diskusi**

---

## 🎯 Golden Rules

### Rule #1: blue is the New Primary
Semua tombol utama, icon highlights, dan primary actions harus menggunakan **blue**:
- Button: `bg-blue-600 hover:bg-blue-700`
- Icon box: `bg-blue-50 text-blue-600`
- Search focus: `focus:ring-blue-500`
- Shadow: `shadow-blue-200`

### Rule #2: Three Views, One Style
Ketika ada perubahan styling atau struktur:
- **index.blade.php** - List view dengan table
- **create.blade.php** - Form untuk tambah data
- **edit.blade.php** - Form untuk edit data

Semuanya harus konsisten dalam:
- Warna
- Typography
- Spacing (padding, margin)
- Border radius & shadows
- Component sizing

### Rule #3: Responsive Mobile-First
```
- Single column pada mobile
- Multi-column di md breakpoint ke atas
- Grid pattern: grid-cols-1 md:grid-cols-2 atau similar
```

### Rule #4: Icons from Heroicons
Semua SVG icons harus dari Heroicons (24px):
```html
<svg class="w-6 h-6" fill="none" stroke="currentColor" viewBox="0 0 24 24">
  <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="..."></path>
</svg>
```

### Rule #5: Permission Checks Required
Semua action buttons harus punya:
```blade
@can('produk-view')
  <!-- View button -->
@endcan

@can('produk-edit')
  <!-- Edit button -->
@endcan

@can('produk-delete')
  <!-- Delete button -->
@endcan
```

### Rule #6: Form Fields Pattern
Setiap input/select harus punya:
```blade
<label class="block text-xs font-semibold text-gray-600 uppercase tracking-wider mb-2">
  Label Text <span class="text-red-500">*</span>
</label>
<input type="..." class="w-full px-4 py-2.5 bg-gray-50 border border-gray-200 rounded-xl text-sm focus:bg-white focus:ring-2 focus:ring-blue-500 focus:border-transparent transition duration-200 outline-none @error('field') border-red-500 bg-red-50/50 @enderror">
@error('field') <p class="text-red-500 text-xs mt-1.5">{{ $message }}</p> @enderror
```

---

## 🚫 Anti-Patterns (JANGAN LAKUKAN)

❌ Jangan ubah warna primary dari blue ke warna lain tanpa izin
❌ Jangan mengubah struktur layout (header, main card, sections)
❌ Jangan mix styling approaches (avoid dark mode classes seperti `dark:`)
❌ Jangan menambah spacing/padding baru yang tidak konsisten
❌ Jangan ubah font sizes, weights, atau tracking
❌ Jangan tambah utility classes tanpa merujuk ke guidelines
❌ Jangan hilangkan permission checks
❌ Jangan ubah hanya 1-2 file tanpa update yang lain

## ✅ When Making Changes

**Scenario: Menambah field baru**
```
1. Tentukan apakah field ini di semua 3 files atau hanya beberapa
2. Gunakan styling yang sama seperti field lain
3. Letakkan dalam section yang tepat
4. Update .instructions.md jika ada pattern baru
5. Test responsiveness di mobile
```

**Scenario: Mengubah styling button**
```
1. Change di index.blade.php
2. Change di create.blade.php
3. Change di edit.blade.php
4. Verify color matches #f97316 (blue-600)
5. Update .instructions.md dengan new class jika diperlukan
```

**Scenario: Fixing bug atau issue**
```
1. Preserve styling - jangan ubah CSS class saat fix bug
2. Hanya ubah HTML structure jika absolutely necessary
3. Notify team jika ada styling change diperlukan untuk fix
```

## 📋 Styling Consistency Checklist

Sebelum commit, cek:

- [ ] Warna primary actions adalah blue (`bg-blue-600`)
- [ ] Icon boxes adalah `bg-blue-50 text-blue-600`
- [ ] Labels uppercase dengan `tracking-wider`
- [ ] Input fields punya `focus:ring-blue-500`
- [ ] Buttons punya correct shadow/hover states
- [ ] Cards punya `rounded-2xl shadow-sm border-gray-100`
- [ ] Table punya correct header styling
- [ ] Permission checks ada di semua action buttons
- [ ] Error messages consistent style
- [ ] Responsive layout tested
- [ ] Pagination ada di index footer
- [ ] Search form di header dengan correct width
