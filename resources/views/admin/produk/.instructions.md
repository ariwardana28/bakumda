# 📋 Style Guidelines - Manajemen Produk Admin

## ⚠️ PENTING: Pertahankan Konsistensi Styling

Ketika membuat, mengubah, atau memperbaharui file views di folder produk, **SELALU** gunakan gaya dan struktur yang sudah ditetapkan. Jangan ubah model tampilan tanpa persetujuan eksplisit.

---

## 🎨 Palet Warna untuk Produk

- **Primary Color**: Orange (`bg-orange-600`, `text-orange-600`, `shadow-orange-200`)
- **Secondary Colors**:
  - Tersedia: Emerald (`bg-emerald-50`, `text-emerald-600`)
  - Habis: Red (`bg-red-50`, `text-red-600`)
  - Pre-order: Amber (`bg-amber-50`, `text-amber-600`)
  - Default/Neutral: Blue untuk peringatan (`bg-blue-50`, `text-blue-600`)

---

## 📐 Struktur Layout yang Wajib Diikuti

### **Index Page** (`index.blade.php`)
```
1. Header Section
   - Judul & Deskripsi di kiri
   - Tombol "Tambah Produk" (Orange) di kanan dengan @can('produk-create')

2. Session Alert (emerald)

3. Main Card (bg-white, rounded-2xl, shadow-sm, border-gray-100)
   - Card Header dengan:
     * Icon box (p-2 bg-orange-50 text-orange-600)
     * Title & subtitle
     * Search form (w-full md:w-72)
   
   - Table dengan:
     * No | Gambar | Nama Produk | Kategori | Status | Aksi
     * Nomor urut otomatis
     * Foto produk 14x14 px
     * Status badge dinamis
     * Aksi: View (sky), Edit (amber), Delete (red) dengan @can checks
   
   - Pagination footer (border-t)
```

### **Create Page** (`create.blade.php`)
```
1. Header Section
   - Judul "Tambah Produk Baru"
   - Tombol "Kembali ke Daftar"

2. Main Form Card
   - Header dengan icon (bg-orange-50)
   - Form sections:
     a) Informasi Dasar Produk
        - Icon: info
        - Nama Produk (text input)
        - Kategori & Status (2 column grid)
        - Deskripsi (textarea)
     
     b) Galeri Foto Produk
        - Icon: image
        - Button "Pilih Foto" (white bg)
        - File preview grid
        - Delete button on hover
     
     c) Varian Ukuran (x-show="kategori === 'Baju'" x-cloak)
        - Icon: grid
        - Button "Tambah Ukuran Baru" (gray-600)
        - Dynamic rows dengan delete button
   
   - Action buttons (Cancel, Submit)
```

### **Edit Page** (`edit.blade.php`)
```
1. Header Section (sama seperti Create, tapi judul "Edit Produk")

2. Main Form Card
   - Header dengan icon (bg-amber-50) - berbeda dari Create
   - Struktur form sama seperti Create, tapi:
     * Semua field sudah pre-filled dengan data produk
     * Bagian Varian Ukuran tidak ditampilkan (hanya untuk create)
   
   - Tampilan Gambar Saat Ini:
     * Grid foto dengan delete button on hover
     * Form untuk delete setiap gambar
   
   - Action buttons (Cancel, "Simpan Perubahan")
```

## 🎯 Styling Rules yang WAJIB DIIKUTI

### **Typography**
- Page Title: `text-3xl font-bold text-gray-850 tracking-tight`
- Section Title: `text-lg font-bold text-gray-800`
- Section Subtitle: `text-xs text-gray-400`
- Label: `text-xs font-semibold text-gray-600 uppercase tracking-wider mb-2`

### **Buttons**
- **Primary Button** (Orange):
  ```html
  bg-orange-600 hover:bg-orange-700 text-white font-bold py-2.5 px-5 rounded-xl shadow-lg shadow-orange-200
  ```
- **Secondary Button** (Gray):
  ```html
  bg-gray-100 hover:bg-gray-200 text-gray-700 font-semibold px-4 py-2.5 rounded-xl
  ```
- **Icon Button** (Action):
  - View: `p-2 bg-sky-50 text-sky-600 hover:bg-sky-100 rounded-lg`
  - Edit: `p-2 bg-amber-50 text-amber-600 hover:bg-amber-100 rounded-lg`
  - Delete: `p-2 bg-red-50 text-red-600 hover:bg-red-100 rounded-lg`

### **Input/Select Fields**
```html
class="w-full px-4 py-2.5 bg-gray-50 border border-gray-200 rounded-xl text-sm focus:bg-white focus:ring-2 focus:ring-orange-500 focus:border-transparent transition duration-200 outline-none"
```
- Error state: `border-red-500 bg-red-50/50`

### **Cards & Containers**
- Main Card: `bg-white rounded-2xl shadow-sm border border-gray-100`
- Section Card: `bg-white rounded-2xl shadow-sm border border-gray-100 p-6 md:p-8 space-y-6 mb-8`
- Icon Container: `p-2 bg-orange-50 rounded-xl text-orange-600`

### **Table Styling**
- Header Row: `bg-gray-50/70 border-b border-gray-100 text-xs font-semibold text-gray-500 uppercase tracking-wider`
- Body Row: `hover:bg-gray-50/50 transition duration-150`
- Border: `divide-y divide-gray-100`

## ✅ Checklist Sebelum Commit

- [ ] Gunakan warna Orange (#f97316) untuk primary actions
- [ ] Semua icons menggunakan SVG inline dari Heroicons
- [ ] Responsive design: `grid grid-cols-1 md:grid-cols-2` untuk 2 kolom
- [ ] Pagination ada di footer dengan border-top
- [ ] Search form width: `w-full md:w-72`
- [ ] Semua form fields punya label dengan uppercase, tracking-wider
- [ ] Error messages: `text-red-500 text-xs mt-1.5`
- [ ] Permissions checks dengan `@can('produk-view|edit|delete')`
- [ ] Tidak ada styling inline kecuali x-data atau x-show
- [ ] Tailwind classes terstruktur rapi

---

## 🔄 Ketika Ada Perubahan Request

**Jika ada request untuk mengubah styling:**
1. Hubungi lead development untuk approval
2. Update guidelines ini jika ada perubahan
3. Terapkan perubahan ke semua 3 file sekaligus
4. Jangan hanya ubah satu file saja

**Jika ada perubahan fungsional yang perlu styling baru:**
- Gunakan palet warna yang sudah ada
- Ikuti structure dan typography guidelines
- Konsultasikan dengan tim sebelum implementasi
